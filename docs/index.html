latex-paper-writing: an agent skill for research paper writing in LaTeX

weinaike

github.com/weinaike/overleaf-latex-skill

Abstract—latex-paper-writing is an open agent skill that turns a coding agent into an end-to-end research-paper assistant. Given a venue, it scaffolds the project with the genuine class files (IEEEtran, acmart, AASTeX), drafts and revises sections against per-venue writing methodology, manages BibTeX citations, compiles the PDF and reports the real errors from the log in plain language, and runs pre-submission checks for page limits and camera-ready rules. It installs into Claude Code, OpenAI Codex, and Gemini CLI with one command [§2].

1Introduction

Writing a paper is a loop: set up the template, draft a section, chase a citation, compile, read the log, repeat. Each step is small; the context switching is what costs a week. This skill moves the whole loop into the coding agent you already have open, so the distance between “new idea” and “submitted PDF” is a conversation.

The skill follows the open Agent Skills format [2]: a SKILL.md operating manual plus the scripts, templates, and reference documents it calls for. Any compatible agent can load it, and the bundled installer wires it into Claude Code, OpenAI Codex, and Gemini CLI [1].

The templates are the genuine article: IEEEtran for IEEE conference and journal papers, acmart for ACM sigconf, AASTeX v7 for AAS journals (class files bundled, since TeX Live does not ship them), and a clean single-column article for arXiv preprints. Writing guidance is baked into the scaffold itself — every section skeleton carries paragraph-level instructions as comments — and deeper methodology is loaded on demand instead of upfront.

2Installation

Clone the repository and run the installer. It detects which agents are installed on your machine and wires the skill into each one (Listing 1).

Listing 1: Install into every agent you have.

git clone https://github.com/weinaike/overleaf-latex-skill.git
cd overleaf-latex-skill
./install.sh              # auto-detect; or: --agent claude | codex | gemini

Claude Code and Gemini CLI receive a live symlink; Codex receives a copy and discovers it when a new session starts (Table 1). To remove it later, run ./install.sh --remove. The installer refuses to overwrite anything it does not recognize as this skill.

Table 1: Where the skill lands, per agent.

AgentMethodNotes
Claude Code~/.claude/skills/, symlinkLive — edits in the repo apply immediately
OpenAI Codex~/.codex/skills/, copyRe-run the installer after updates; new sessions only
Gemini CLI~/.gemini/skills/, symlinkOr native: gemini skills install <repo> --path latex-paper-writing

3What it does

The skill organizes the work into five workflows, and the agent picks the right one from what you ask for — you never have to remember any of this:

  • Scaffold. new_paper.sh creates a project for one of five venues, with section skeletons, a sample references.bib, and a figures/ directory.
  • Draft and revise. Section-by-section writing against per-venue methodology; every skeleton explains what each paragraph is for.
  • Citations. BibTeX entry sourcing and hygiene; broken-citation debugging.
  • Compile and debug. compile.sh builds the PDF and extracts the real errors from the log in readable form.
  • Pre-submission checks. Page limits, anonymization, and camera-ready rules, per venue.

Deep-dive references — writing methodology, venue style rules, BibTeX hygiene, error troubleshooting — are read only when a workflow needs them, so the agent’s context stays on your paper.

5Requirements and availability

Compilation needs a TeX installation (pdflatex, bibtex); scripts/check_latex_env.sh diagnoses a broken one. Source, issue tracker, and the full operating manual live in the repository [1].
