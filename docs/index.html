What it does

One skill covers the whole loop, so you stay in one conversation from blank page to submitted PDF.

Real venue templates

IEEE conference, IEEE journal, ACM sigconf, arXiv, and AAS journals — using the genuine class files, with AASTeX bundled.

Section drafting

Every section skeleton explains what each paragraph is for. Drafting and revising follow per-venue methodology.

BibTeX citations

Sources real entries, keeps the database clean, and fixes broken citations.

Compile and fix

Builds the PDF and pulls the actual errors out of the log in plain language.

Pre-submission checks

Page limits, anonymization, and camera-ready rules for your venue.

Loads only what it needs

Writing guides, venue style rules, and error references are read on demand — never all at once.

How it works

Install once, then just talk to your agent.

Step 1

Install

Clone and run the installer. It wires the skill into every agent it finds.

./install.sh --agent claude
# or codex / gemini / all

Step 2

Say what you want

"Start an IEEE conference paper on…" or "fix my citations" — the skill picks the right workflow.

Start an IEEE conference paper
on robust localization

Step 3

Get a compiling PDF

The agent runs the loop — draft, cite, compile, fix — and reports pre-submission issues before you ship.

compile.sh ~/papers/my-paper full
# full rebuild before shipping

Compilation needs pdflatex and bibtex — check_latex_env.sh diagnoses your setup.
